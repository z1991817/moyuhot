# 摸鱼热榜改进路线图

这份清单用于补齐和同类热门项目相比最影响体验、传播和 Star 转化的短板。

## P0：降低首次使用门槛

- **全家桶一键启动**：已提供 `ops/docker-compose.full.yml`，新用户可以一条命令启动 SeeSea、API、前端和 Nginx。
- **公共只读 API 兜底**：建议生产站点稳定后，提供一个只读 API 示例地址，例如 `https://moyuhot.com/api`，让自部署用户可以先跳过 SeeSea。
- **README 首屏体验路径**：保留在线地址、全家桶启动命令、健康检查命令，减少用户理解成本。

## P1：补传播素材

- **首页截图**：在 `docs/images/` 放桌面端和移动端截图，并在 README 顶部展示。
- **动图演示**：录一个 10 秒 GIF，展示打开首页、切换页面、查看行情。
- **Open Graph 图**：增加社交分享封面图，让 GitHub、X、Telegram、微信卡片更清楚。

## P1：强化产品定位

- **避免和新闻阅读器硬碰**：主定位保持“摸鱼工作台”，不是长文阅读器。
- **突出财经差异化**：A 股、美股、热榜同屏是当前和 NewsNow 类项目最明显的差异。
- **强调合规边界**：只展示标题和原站链接，不抓正文、不缓存图片、不做摘要。

## P1：增加可信度

- **截图式部署结果**：README 增加 `docker compose ps` 和健康检查示例。
- **故障排查文档**：补 `docs/TROUBLESHOOTING.md`，覆盖端口占用、SeeSea 不健康、行情接口为空、容器构建慢。
- **版本说明**：补 `CHANGELOG.md`，每次上线用 3-5 条说明变化。

## P2：贡献入口

- **新增平台说明**：补清楚平台映射、图标、分类、后端默认列表在哪里改。
- **Good First Issue**：准备几个简单 issue，例如补图标、补平台文案、补移动端样式。
- **PR 模板**：增加 `.github/pull_request_template.md`，让贡献者知道要附截图和测试结果。

## P2：工程体验

- **镜像发布**：发布 `ghcr.io/z1991817/moyuhot-api` 和 `ghcr.io/z1991817/moyuhot-frontend`，减少用户本地构建时间。
- **Compose profiles**：后续可以把全家桶、外接 SeeSea、仅前端预览做成 profile。
- **端到端冒烟测试**：用 Playwright 或 curl 脚本验证首页、健康检查和核心 API。

## P3：高级能力

- **默认只读 API**：如果你愿意承担流量，可以给自部署用户一个只读上游，先体验再自建。
- **PWA/桌面小窗**：让它更像常驻摸鱼面板。
- **个性化同步**：短期先用 localStorage，长期再考虑账号同步。

## 暂不做

- **MCP/AI**：当前不作为核心卖点，避免分散定位。
- **正文抓取/摘要**：和项目合规边界冲突，也会增加版权和运营风险。
- **重型社区功能**：评论、收藏、推荐流都不是当前阶段优先项。
